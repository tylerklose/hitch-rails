# Work packet: M5.1

## Scope

Ship the MCP installer that creates one host-owned API controller, route before
the engine mount, initializer settings, and empty explicit registry. Refuse
missing auth installation/migrations and every file/route/constant collision;
support the explicit controller-name escape hatch and an exact rollback
manifest without overwriting customized files.

## Not in scope

- Generating/registering tools, production deployment, auto-discovery, or
  choosing host policy.
- Overwriting existing controller/route/configuration/registry code.

## Target files/API

- `lib/generators/hitch/mcp/install_generator.rb` and templates.
- generator integration/collision/rollback tests and the M4.5-created
  `bin/ci-generators` install target.
- install/removal docs and generated-file manifest.

`hitch:mcp:install` and its flags/output are public operational API.

## Dependencies

M4.5 integrated contract/mutation gate is accepted.

## Acceptance commands

Run:

```sh
bin/ci-generators install
bin/contract
bin/rubocop
```

Run the real generator in temporary apps; assert route order, API controller,
default-deny config, collisions, custom controller name, idempotent refusal, and
non-destructive rollback.

## Evidence paths

Create `docs/evidence/0.2.0/generators/mcp-install.json` with permutations,
generated paths/checksums, collisions, and rollback results.

## Rollback

R1: revert generator code/docs/tests. Generated hosts follow their captured
file manifest; never delete customized files automatically.

## Estimate

Three engineering days. Risk is medium because generator collisions can damage
host code.

## Risks

- Template inspection does not prove generated output.
- Route insertion can leave the endpoint shadowed by the engine.
- Re-running can overwrite operator changes.

## Owner

The Hitch release maintainer owns generator and rollback acceptance.
