# Work packet: M3.3

## Scope

Resolve the configured host scope once per request, evaluate deny-default
`.available_to?`, filter by static token scopes, and expose a deterministic MCP-
name-sorted list. Unknown and unavailable names share the same result; only a
known available tool may produce a scope step-up. Add public test helpers for
host application integration without exposing adapter internals.

## Not in scope

- Argument-aware authorization, host execution, Result values, rate stores, or
  persistent audit records.
- Caching context/availability across requests or disclosing scopes for hidden
  tools.

## Target files/API

- Registry filtering and endpoint list/discovery integration.
- `Hitch::MCP::Tool.available_to?` deny-default behavior and documented test
  helpers.
- `test/integration/mcp_listing_test.rb`, resolver failure tests, and concurrent
  principal/reload isolation tests.

Public behavior is the filtered list and test-helper contract; resolver and
snapshot machinery remain private.

## Dependencies

M3.2 registry validation/reload behavior is accepted.

## Acceptance commands

Run:

```sh
bin/ci-test test/integration/mcp_listing_test.rb
bin/ci-sdk min
bin/ci-sdk latest
```

Tests prove ordering, unknown/unavailable indistinguishability, static-scope
precedence, nil/raising resolver failure, optional client info, and simultaneous
principal isolation.

## Evidence paths

Create `docs/evidence/0.2.0/registry/listing-isolation.json` with synthetic
principal cases, ordered names, failure categories, and concurrency outcomes.

## Rollback

R1: revert listing/filter/helper changes with their tests.

## Estimate

Three engineering days. Risk is high because filtering is an authorization and
disclosure boundary.

## Risks

- Filtering only the response while constructing the SDK with all tools leaks
  callability.
- Scope errors can reveal hidden registrations.
- Memoized availability can cross principals or reloads.

## Owner

The Hitch release maintainer owns filtered-list and isolation acceptance.
