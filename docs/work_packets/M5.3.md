# Work packet: M5.3

## Scope

Ship `hitch:doctor`, request-admission operator guidance, upgrade/removal docs,
and a repository-wide prose audit. Doctor reports versions/config/resource and
discovery coherence/route order/migrations/registry/hosts/origins/admission-store
connectivity plus isolated atomicity/expiry/package/legacy-endpoint checks with
stable machine and human output.

## Not in scope

- Mutating production configuration/data, automatically fixing findings,
  deleting host files/tables, or implying memory-store production support.
- Deployment/adoption or product-client approval.

## Target files/API

- `lib/tasks/hitch.rake` doctor task and private diagnostic checks.
- operator, request-admission, upgrade, removal, and public API documentation.
- `bin/doctor-fixtures` (new), expanded `bin/prose-audit`, and task fixture tests.

Doctor command/output categories are public operational API; diagnostic internals
are private.

## Dependencies

M5.1 and M5.2 generator contracts are both accepted.

## Acceptance commands

Run:

```sh
bin/doctor-fixtures
bin/prose-audit
bin/ci-generators install
bin/ci-generators tool
```

Fixtures cover healthy and every actionable failure while features are enabled
or disabled as documented. Prose audit searches code/comments/docs/tests/
warnings/changelog for every superseded mechanism.

## Evidence paths

Create `docs/evidence/0.2.0/operator/doctor-snapshots.json` and
`docs/evidence/0.2.0/operator/prose-audit.json` with redacted fixture categories,
patterns, allowlists, and zero stale matches.

## Rollback

Three engineering days. Risk is high because false diagnostics or stale prose
