# Work packet: M6

## Scope

With Tyler-granted access, replace the Skillit-root copied-lineage mechanism in
one approved host. Upgrade its SDK behind the old route first, validate Hitch on
an isolated preview, preserve names/schemas/auth/audit meaning, atomically swap
the canonical route, remove duplicate dispatch, benchmark equal host/data, and
record every override/friction point before `0.2.0.rc1`.

## Not in scope

- Entering the private host without explicit access, changing business policy,
  running fake production sales/payments, or counting copied-lineage friction as
  independent evidence.
- Exposing old and new production routes simultaneously.

## Target files/API

- Approved copied-lineage host changes and its private adoption report.
- Hitch adoption evidence index and any failing acceptance test required before
  a framework change.
- Same-host benchmark: 1,000 warmed list/call requests, concurrency 16, five
  runs, zero errors, median p95 regression no worse than 15% absent an accepted
  performance issue.

No Hitch public API expands from one copied-lineage request alone.

repository/deployment access and approves the named copied-lineage host or a

M5 deferred publication, install the exact accepted internal artifact.
