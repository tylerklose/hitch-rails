# Work packet: M1.1

## Scope

Freeze the extraction dossier before public API design. Pin every inspected
repository to a commit and source-file set, record Skillit as the only design
root for the Kaffe Karma and Perfect Roofing descendants, and record Stash as
the second independent root. Classify every proposed mechanism as
standards-required, independently converged, copied lineage, host policy, or
rejected; two roots must never be described as three.

## Not in scope

- Changing any source repository or importing its code.
- Treating copied survival as independent convergence.
- Adding runtime MCP constants, dependencies, endpoint behavior, or registry
  behavior.
- Granting access to adoption hosts or approving M6/M7 deployment work.

## Target files/API

- `docs/architecture/extraction.md`: human-readable lineage and decision
  narrative with explicit two-root limit.
- `docs/architecture/extraction_sources.yml`: pinned, redacted source records
  with commits and relative paths.
- `docs/architecture/extraction_matrix.yml`: one classification and disposition
  for every extracted idea.
- `bin/verify-provenance` (new): schema, lineage, independence, and matrix
  verifier that never requires access to the private repositories.
- `test/tooling/verify_provenance_test.rb` (new): isolated mutation fixtures for
  false independence, missing pins, unknown sources, and unclassified ideas.

These are design evidence and contributor tooling, not gem runtime API.

## Dependencies

M1.0 is accepted: all issue packets and the exact roadmap graph exist. The M0.5
internal checkpoint remains a predecessor; preparing this dossier does not waive
that evidence gate or turn it into a publication requirement.

## Acceptance commands

Run:

```sh
bin/verify-provenance
bin/ci-test test/tooling/verify_provenance_test.rb
bin/rubocop
```

The verifier must fail if copied descendants increase the independent-root
count, a commit is not a full SHA, a source path is absolute, a matrix source
is unknown, or a classification/disposition is missing.

## Evidence paths

Create `docs/evidence/0.2.0/contract/provenance-verification.json` with the two
root IDs, pinned source IDs, matrix row count, command outcomes, and dossier
checksums. Do not include private URLs or local machine paths.

## Rollback

R1: revert dossier, verifier, tests, and evidence together. No runtime or schema
state changes.

## Estimate

Two engineering days. Risk is medium because false independence would justify
public abstractions that the evidence does not support.

## Risks

- Similar file trees can conceal copied lineage.
- A moving branch name is not reproducible provenance.
- Private source paths or remote URLs can leak through evidence.
- A matrix can appear exhaustive while silently omitting rejected ideas.

The Hitch release maintainer owns classification acceptance. Tyler Klose owns
