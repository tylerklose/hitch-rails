# Work packet: M7

## Scope

With Tyler-granted access, adopt Hitch in Stash or another approved tools-only
host whose MCP design did not descend from Skillit, Kaffe Karma, or Perfect
Roofing. Map its existing visibility and record policy into Hitch's two gates,
turn friction into failing Hitch acceptance tests before framework changes, and
prove tool/principal/reload isolation before `0.2.0.rc2`.

## Not in scope

  weakening host policy, or relabeling a copied host independent.
- Treating deployment success alone as API validation.

- Approved independent host changes and private adoption report.
- Hitch acceptance tests for independently repeated friction.
- redacted provenance, isolation, semantic parity, and rollback evidence.

Incompatible redesign returns to M3/M4 and repeats both adoptions; it does not
receive a hidden compatibility shim.

## Acceptance commands

Run the host-owned CI, MCP smoke, and isolation commands documented in the
private report. Then run:

```sh
bin/contract
HITCH_MILESTONE_LOCAL_GATE_REPORT=/tmp/m7-mutation-mcp.json \
  bin/milestone-local-gate M7 mutation_mcp
bin/verify-release-evidence --through M7
```

The verifier derives meaningful `app`/`config`/`db`/`lib`/gemspec and public-
manifest deltas from RC1 to RC2 instead of trusting the friction declaration.
The version file is mechanical only when no byte except the exact RC1-to-RC2
version literal changes. Any framework change requires a failing-test-before-
fix proof whose red commit contains no earlier framework or dependency
implementation, plus fresh copied-host and independent-host reruns, each bound
to the exact RC2 commit/tree, artifact SHA, completion time, redacted command,
and distinct reviewed report. It also requires an exact independent-root or
approved-substitute provenance basis, binds initial external gate results to
the private host report, requires an approval-bound repository identity and
report distinct from M6, validates the generated source-bound mutation report,
and reconstructs the `0.2.0.rc2` gem from its recorded
source commit/tree and SHA-256.
