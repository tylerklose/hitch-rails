# Work packet: M6

## Scope

With Tyler-granted access, replace the Skillit-root copied-lineage mechanism in
one approved host. Upgrade its SDK behind the old route first, validate Hitch on
an isolated preview, preserve names/schemas/auth/audit meaning, atomically swap
the canonical route, remove duplicate dispatch, benchmark equal host/data, and
record every override/friction point before `0.2.0.rc1`.

## Not in scope

- Entering the private host without explicit access, changing business policy,
  running fake production sales/payments, or counting copied-lineage friction as
  independent evidence.
- Exposing old and new production routes simultaneously.

## Target files/API

- Approved copied-lineage host changes and its private adoption report.
- Hitch adoption evidence index and any failing acceptance test required before
  a framework change.
- `docs/contracts/release_evidence.yml`, `docs/evidence/0.2.0/index.json`, and
  the fail-closed `bin/verify-release-evidence` acceptance rail.
- `bin/prepare-release-artifact --checkpoint` and `bin/milestone-local-gate`,
  which first become available at this packet and remain reusable downstream.
- Same-host benchmark: 1,000 warmed `tools/list` requests and 1,000 warmed
  `tools/call` requests, concurrency 16, five runs, zero errors per operation,
  and per-operation median p95 regression no worse than 15% absent an accepted
  performance issue.
- Source-bound `0.2.0.rc1` checkpoint: full commit, exact tree, artifact name,
  SHA-256, and internal/public status consistent with the M5.4 decision.

No Hitch public API expands from one copied-lineage request alone. The RC1
manifest may differ from pre.4 only by the reviewed
`endpoint_registry_prepare_cycle` documentation erratum, which corrects
per-request constantization to per-request immutable-snapshot reads plus
per-prepare-cycle constantization. The verifier derives and rejects any other
manifest delta.

## Acceptance commands

Run the host-owned CI, MCP smoke, isolation, and benchmark commands documented
in the private adoption report. Then run:

```sh
bin/contract
HITCH_MILESTONE_LOCAL_GATE_REPORT=/tmp/m6-package-smoke.json \
  bin/milestone-local-gate M6 package_smoke
bin/verify-release-evidence --through M6
```

The milestone gate validates the indexed redacted manifest and exact artifact,
parity, route, benchmark, friction, approval, and checkpoint fields. Each gate
records status, verification class, redacted command, and report SHA-256;
external gates bind the private host report. The generated package-smoke report
binds its fixed command to the clean RC1 source, gem bytes, output digest, and
structured package report. The verifier rebuilds the RC gem
from its recorded source commit/tree and exact SHA-256, and requires RC1 to
descend strictly from the accepted pre.4 commit. It also derives every
meaningful `app`/`config`/`db`/`lib`/gemspec delta from pre.4 to RC1. The version
file is mechanical only when its entire content is unchanged after replacing
the exact `0.2.0.pre.4` literal with `0.2.0.rc1`. Any framework change must have
a failing-test-before-fix proof whose red commit contains no earlier framework
or dependency implementation, plus a fresh copied-host rerun bound to the
resulting RC1 commit/tree, artifact SHA, completion time, and private-report
digest. Private raw logs remain in the authorized host.
